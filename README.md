# CryptoLab — From Elliptic Curves to Ethereum Wallets

An educational static website for two cryptography homework assignments. It is built with plain HTML, CSS and JavaScript and can be published using GitHub Pages.

## Contents

- `index.html` — project landing page
- `homework-1/` — toy elliptic-curve scalar multiplication, step-through controls, discrete point plot and coordinate frequency charts
- `homework-2/` — interactive wallet-pipeline explainer, derivation-path breakdown, historical timeline and references
- `assets/style.css` — shared responsive styling

## Run locally

No build tools or package installation are required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Navigate to each homework from the landing page.

For more realistic local testing, use Visual Studio Code's Live Server extension or run a simple local static server. Do not use real wallet secrets in this project.

## Publish with GitHub Pages

1. Create a public GitHub repository (for example, `cryptolab`).
2. Upload all files while preserving the directory structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to complete and open the URL displayed in the Pages settings.

The URL for a project site usually has the form `https://USERNAME.github.io/REPOSITORY/`. Replace the placeholders with your actual GitHub username and repository name.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Important mathematical notes

Homework 1 uses the toy curve `y² = x³ + 7 (mod 17)` and base point `G = (1, 5)`. With the standard point-addition rules, `6G = (1, 12)` and `G` has order 7. This tiny group is intentionally insecure and is used only to illustrate the mechanics.

The statistical charts describe the small subgroup generated by `G`; they cannot establish cryptographic security, uniformity on a real curve, or a hash-like avalanche effect.

Homework 2 is a conceptual explainer, not a wallet implementation. It intentionally does not generate addresses from user-provided mnemonics or private keys.
