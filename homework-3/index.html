EXPERIMENT 03 · ECC AND CRYPTANALYSIS

Two ciphers,
two different weaknesses.

Explore elliptic-curve encryption and the Caesar cipher, then investigate how statistical analysis and restricted-key searches can reveal secrets. Compare the methods, their assumptions, and their limitations through interactive experiments.

01 / ECC message encryption

Explore a toy elliptic-curve ElGamal construction. The private key is d, the public key is Q = dG, and an ephemeral scalar r is used to encrypt each message byte as a point on the curve.

Educational use only. This demonstration uses secp256k1 arithmetic but restricts private and ephemeral scalars to a small range. It is not a production-ready encryption system.

Each byte m is represented as M = mG. Decryption computes C₂ − dC₁ = M and searches the 256 possible byte values to recover the original message.

Run the experiment to display the public key, ciphertext summary, and recovered message.

02 / Caesar cipher

The Caesar cipher shifts each letter by a fixed number of positions in the alphabet. Its key space contains only 26 possible shifts, making exhaustive search straightforward.

Letters are shifted while spaces, punctuation, and letter case are preserved.

03 / Statistical attack on Caesar

Estimate the encryption key by comparing the letter frequencies of candidate decryptions with typical English frequencies. The chi-square score ranks candidates, but does not guarantee that the best candidate is correct.

Run the analysis to rank the candidate shifts.

04 / Restricted-key ECC attack

Given a public point Q, test candidate private keys d until the equation dG = Q is satisfied. The experiment demonstrates why restricting the possible private keys makes recovery feasible.

05 / Comparing the attacks

Both experiments aim to recover secret information, but they exploit different weaknesses.

Property Caesar ECC toy
Key space 26 shifts At most 1,000 candidates
Attack input Ciphertext and language statistics Public point Q and candidate interval
Method Frequency analysis Test whether dG = Q
Limitation Short texts can mislead the statistical estimate The search is feasible only because the key range is restricted

Interpretation, not overclaiming

  • Caesar encryption preserves statistical patterns in the language.
  • Frequency analysis is less reliable for short texts or text that differs from the reference language.
  • The ECC attack searches a deliberately restricted key space; it does not break secp256k1 at its normal security level.
  • A uniformly random 256-bit private key cannot feasibly be recovered by exhaustive search with ordinary computing resources.

Real-world ECC encryption requires a carefully specified construction with secure randomness, key derivation, authenticated encryption, and robust message encoding. Implementations may also be vulnerable to side channels, key leakage, or protocol mistakes.
