EXERCISE 01

Riemann vs Lebesgue Integration

Two perspectives on the same integral: partitioning the domain or partitioning the range.

Two ways to approximate an area

The Riemann approach divides the domain into small subintervals. In each interval, the function is represented by a selected value, and the corresponding rectangle contributes to the total area. As the partition becomes finer, the approximation generally improves for Riemann-integrable functions.

Riemann sum ∑ f(xᵢ*) Δx

The Lebesgue point of view reverses the order of the construction. Rather than asking what value the function takes at each small piece of the domain, we group together points where the function has similar values. We then multiply each representative value by the measure of the set of points mapped into that range interval.

Lebesgue-inspired sum ∑ yⱼ* · measure({x : f(x) ∈ Iⱼ})

In the experiment below, the measure of each preimage is estimated by counting sampled domain points. This is a numerical approximation of the Lebesgue idea, not an exact measure-theoretic computation.

A MATHEMATICAL EDGE CASE

When a numerical grid can be misleading

The Dirichlet function is equal to 1 at rational numbers and 0 at irrational numbers. Since rational and irrational numbers are both dense in every interval, the function is discontinuous everywhere. It is therefore not Riemann integrable. However, the rationals have Lebesgue measure zero, so its Lebesgue integral on [0, 1] is 0.

A uniform numerical grid usually contains only rational sample points. A naive implementation would therefore return 1 for the Riemann-style sample average. The Lebesgue-inspired calculation in this demonstration uses the known measure of the level sets and returns 0. This special handling illustrates why mathematical knowledge about a function can be essential when numerical sampling is insufficient.

Thomae's function behaves differently. It is 1/q at a rational number p/q in lowest terms and 0 at irrational numbers. It is discontinuous at rational points but continuous at irrational points. It is Riemann-integrable and its integral is 0. A finite grid can still produce a small positive estimate, which decreases as the sampling resolution improves.

Comparison and interpretation

For bounded Riemann-integrable functions, the Riemann and Lebesgue integrals agree. The difference is not the final value, but the way the integral is constructed. The Lebesgue framework is more general: it can integrate functions, such as the Dirichlet function, that are not Riemann-integrable.

Computational efficiency depends on the implementation. A Riemann sum requires evaluating the function at domain sample points. The range-based method also needs sampled function values, followed by assigning them to range bins and counting the corresponding preimages. With a simple histogram implementation, this additional grouping step has a cost, but it can be useful when the distribution of function values is itself important.

EXERCISE 02

Numerical Computation of the Normal CDF

Computing probabilities from the Gaussian curve without relying on an elementary antiderivative.

Why is the normal CDF special?

The standard normal density is φ(x) = (1 / √(2π)) e−x²/2. Its cumulative distribution function is the area under this density from minus infinity to x. Unlike many elementary integrals, the antiderivative of the Gaussian exponential cannot be expressed using a finite combination of elementary functions.

This is a consequence of the differential-algebraic criterion described by Liouville's theorem on elementary antiderivatives. In this case, the integral of e−x² does not have an elementary primitive. This does not mean that the integral is undefined or cannot be represented exactly: it means that a new special function is needed.

Standard normal CDF Φ(x) = ∫−∞x φ(t) dt

The error function provides exactly this representation:

Connection with erf Φ(x) = ½ [1 + erf(x / √2)]

Special functions give a compact analytical definition, but practical software still needs numerical algorithms to evaluate them. Different algorithms are useful in different regions of the input range, especially in the tails where subtracting a number close to 1 can lose numerical precision.

Interpreting the methods

Simpson's rule approximates the integral directly. The power series evaluates the error function through its Taylor expansion. The third method uses a compact polynomial approximation to the complementary error function. Their speed and accuracy depend on the input and the chosen numerical parameters.

How the three methods work

A

Numerical integration — Simpson's rule

Using symmetry, Φ(x) can be written as ½ plus the signed integral of the density from 0 to |x|. Simpson's rule approximates this integral by fitting quadratic polynomials over pairs of subintervals. It is accurate for smooth functions and its error decreases rapidly as the step size is reduced.

B

Power series expansion of erf

The error function has the expansion erf(z) = (2/√π) Σ [(-1)n z2n+1 / (n!(2n+1))]. The terms can be accumulated recursively, avoiding repeated factorial calculations. This is convenient for moderate values of z, although many terms may be needed as |z| grows.

C

Approximation based on erfc

The complementary error function can be approximated with a rational-polynomial expression. It requires only a small number of arithmetic operations and is therefore fast. The approximation used here is intended for demonstration; production libraries generally use more carefully tuned algorithms to maintain accuracy across the full floating-point range.

FINAL OBSERVATIONS

What do these experiments tell us?

Integration depends on perspective

Riemann and Lebesgue integration agree for functions that are Riemann-integrable, but the Lebesgue framework covers a wider class of measurable functions. The Dirichlet function is a clear example of this difference.

Resolution is not everything

Increasing the number of samples usually improves a numerical approximation, but it does not automatically solve every problem. Pathological functions show that the choice of sampling strategy and mathematical assumptions also matter.

Special functions make computation practical

The normal CDF has an exact representation through erf, even though it has no elementary antiderivative. Numerical algorithms make this representation usable in statistical applications.
